# Мобильное меню портала — макет «до и после»

Макет оптимизации мобильной шторки портала (`web/public/sidebar.js`, `@media ≤768px`).
Канва: https://claude.ai/code/artifact/7026feb8-5244-4592-bada-cce3f655d16b

## Файлы

| Файл | Что это |
|---|---|
| `Main.dc.html` | Доска «Было / Стало», 960 × 1200. Картинка для обсуждения, не кликается. |
| `After.dc.html` | Экран «Стало» в натуральную величину, 390 × 844. Отсюда переносим в код. |
| `Pin.dc.html` | Закрепление строк: долгое нажатие и режим правки меню, 1360 × 1900. |
| `canvas.json` | Раскладка артбордов на канве. |
| `mobile-menu-do-posle.html` | Собранная канва (пересобирается из файлов выше, в гит не кладём). |

## Что меняется

1. **Поиск** переезжает из подвала под логотип. Подсказки открываются ВНИЗ — правило
   `#app-sidebar .sb-search-results { bottom: calc(100% + 6px) }` меняется на `top`.
2. **Быстрый доступ** — Чаты, Лиды, Уведомления первым экраном, до групп. Из своих групп
   эти пункты УБИРАЮТСЯ: дублей страниц в меню быть не должно (`docs/rules/ui.md`).
3. **Виджеты** вместо подвала — плитки `.ui-tiles` / `.ui-tile` из `ui.css`, 3 в ряд
   (`--ui-tile-cols`), зазор 8 px (`--ui-tile-gap`): Главная, Тема, «Копия для ИИ».
   Ниже широкая плитка «Масштаб» с А− / А+ (`ui-scale.js`).
4. **Разделы** свёрнуты по умолчанию, со счётчиком пунктов и шевроном. Механика уже есть —
   `.sb-group.collapsed` / `.sb-items.collapsed`; на мобильном меняется только состояние
   по умолчанию (сейчас `sb-items` принудительно разворачиваются, `sidebar.js`).
5. **Зона тапа** — строка меню поднимается с 32 до 44 px (`--ui-tap`), закреплённая строка 52 px,
   плитка 76 px.

## Новый виджет «Копия для ИИ»

Кладёт в буфер markdown-блок для передачи ИИ-агенту: полный адрес с query и хешем, версия
платформы и модуля, роль и арендатор, размер окна и `--ui-zoom`, тема, последние ошибки консоли
и упавшие запросы (адрес, код, тело ответа), выбранные фильтры страницы. Подтверждение — общий
`uiToast('Скопировано')`. Кнопка — иконочная роль, значок `i-copy` (см. `BTN_ROLES`).

## Закрепление строк (`Pin.dc.html`)

Любую строку меню можно поднять в «Быстрый доступ». Два входа в одно и то же действие:

- **Долгое нажатие** (мобилка) — строка приподнимается, вокруг гаснет, справа проявляется кнопка;
  вибро-отклик, тост `uiToast` с «Отменить». Порог удержания: вы называли 2 с — предлагаю
  **500–600 мс**, при двух секундах жест ощущается как зависание, а не как жест. Это одно число.
- **Режим правки** (`i-edit` в шапке сайдбара) — работает и на ПК, и на мобилке, находится без
  подсказки. Все группы раскрыты, у каждой строки кнопка, у закреплённых — `i-grip-vertical`
  для перетаскивания. Выход — «Готово» (`i-check`).

Ставить оба: жест для того, кто уже знает; режим правки — для всех остальных и как единственный
способ на ПК, где долгого нажатия нет.

### Значок: НЕ `i-pin`

В `assets/icons.svg` под именем `i-pin` лежит **гео-метка**, и она занята местом на карте —
`place-field.js`, `medcard_life.js`, `sex.js`, `crm-chats.html`, `patient-auth.html`. Взять её под
закрепление — сломать смысл значка на пяти страницах. Нужен НОВЫЙ символ `i-pushpin`
(канцелярская кнопка, Lucide `pin`), штрих 2, как весь спрайт:

```svg
<symbol id="i-pushpin" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M12 17v5"/><path d="M9 10.76a2 2 0 0 1-1.11 1.79l-1.78.9A2 2 0 0 0 5 15.24V16a1 1 0 0 0 1 1h12a1 1 0 0 0 1-1v-.76a2 2 0 0 0-1.11-1.79l-1.78-.9A2 2 0 0 1 15 10.76V7a1 1 0 0 1 1-1 2 2 0 0 0 0-4H8a2 2 0 0 0 0 4 1 1 0 0 1 1 1z"/></symbol>
```

Состояние — цветом, а не заливкой (как `.sb-link.active .ico`): закреплено — `--ui-brand`,
не закреплено — `#555`. Отдельный `pin-off` не нужен, кнопка работает переключателем.
Сама кнопка — **только** `class="ibtn"`, без `btn` и модификаторов, и без локального CSS
(`docs/rules/ui.md`); до зоны тапа растягивается `min-width` / `min-height`, не `width` / `height`.

### Где хранится

Список свой у каждого пользователя, порядок задаёт он же. Ключ `cf_pins_v1` в localStorage
по образцу `cf_places_v1` (недавние места); строка опознаётся по `href`. Модуль общий на портал
(`sidebar.js`) и кабинет (`cab-sidebar.js`) — не две копии: правка «поменять порядок» иначе
прилетит в каждую отдельно.

Решить до реализации: localStorage или строка в `settings` на пользователя. localStorage проще
и не требует API, но список не переезжает между устройствами.

## Значения

Цвета — токенами `var(--ui-*, литерал)` (ADR-142), проверять в обеих темах.

| Роль | Токен | Фолбэк |
|---|---|---|
| Фон шторки и страницы | `--ui-bg` | `#0a0a0a` |
| Плитка, поле поиска, карточка быстрого доступа | `--ui-surface-3` | `#101010` |
| Рамка плитки | `--ui-line-2` | `#1e1e1e` |
| Рамка кнопок масштаба | `--ui-line` | `#262626` |
| Текст | `--ui-tx` | `#e8e8e8` |
| Текст вторичный | `--ui-tx-2` | `#8b8b8b` |
| Подписи разделов, счётчики | — | `#555` |
| Акцент, активная строка и рамка поиска | `--ui-brand` | `#00a0ff` |
| Бейдж непрочитанного | — | `#e05252` |

- Скругления: плитка 8, карточка быстрого доступа и поиск 10, шторка сверху 14, бургер 10.
- Подсветка активного: `linear-gradient(90deg, rgba(0,160,255,.14), rgba(0,160,255,.03))` —
  как у `.sb-link.active` сейчас.
- Кегль: подпись раздела 10 / `letter-spacing .08em` / uppercase, строка меню 14,
  закреплённая строка 15 / 600, подпись плитки 12.
- Иконки: Lucide из `/assets/icons.svg`, штрих 2 (`--ui-ico-stroke`); 20 px в закреплённых
  строках и плитках, 18 px в строках разделов, 17 px в поиске.
- Шрифт: `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`.

## Заглушки в макете

Версия в логотипе — `v[версия]`. Числа в бейджах (7 / 12 / 24) взяты как образец, реальные
приезжают из тех же запросов, что и сейчас (`/notify`, `/crm/chats` в `sidebar.js`).

## Пересобрать канву

```
node <skill>/seed-canvas.mjs --template <skill>/payload.template.html \
  --out mobile-menu-do-posle.html --title "Мобильное меню портала" \
  --artboard Main.dc.html --artboard After.dc.html --canvas canvas.json
```
