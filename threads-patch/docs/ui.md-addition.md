## «Треды» (/discuss): сводный список — только чтение и честные счётчики (27.10.2026, ADR-<номер>)

- Сводный список чужих сущностей (обсуждения, чаты, посты) — одна ручка-агрегатор с readonly-соединением; запись
  («ответить») — только в исходной карточке, кнопка «Открыть». Превью ничего не отмечает прочитанным (не звать
  `GET /api/business/chats/:id/messages` — он сбрасывает unread_count).
- «Непрочитанное» показываем только там, где оно хранится по-настоящему (чаты: `unread_count`). Нет данных — `null`
  и другой признак (`awaiting`: последнее слово за клиентом), а не выдуманное число.
- Счётчики вкладок считаются от поиска, но не от выбранной вкладки и курсора; обрезанный список — «Показать ещё ·
  осталось N».
- Поиск страницы — «/», Ctrl/⌘+K не перехватывать (поиск меню).
- Строка треда `.dc-row` (аватар/стопка, заголовок + время, источник, последняя реплика + `.ui-badge`) — кандидат
  в кит M-81; до этого — только в discuss.css.
