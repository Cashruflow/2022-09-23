- **«Треды» (/discuss, 27.10.2026, ADR-<номер>).** Модуль `web/discuss.js` открывает tasks.db `readonly` и не пишет
  ни строки. Новый источник в «Треды» — функцией-экспортом владельца через `app.locals` (как `threads.posts()`,
  `chatDisplayName`), не копией его SQL-правил. Ожидаемые отказы — 403 (нет права раздела) и 422 (неверный id,
  запись исчезла), не 404. Роль с областью own_projects получает только задачи/тикеты своих проектов; чтобы открыть
  ей раздел, кроме галочки на /roles нужна строка `{ r: true, p: "/api/discuss" }` в `SCOPE_API` (role_scope.js).
