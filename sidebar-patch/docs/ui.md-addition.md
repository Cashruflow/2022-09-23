## Сайдбар: кнопка свернуть, поиск-фильтр, значки, хоткеи (02.10.2026)

- Свернуть/развернуть — кнопка `#sb-collapse` на границе (`sb-resize.js`): подложка — обёртка-div на
  токенах, сама кнопка голая `.ibtn`. Клик = двойной щелчок по границе (`setIcons` + `apply(true)`),
  снаружи — только `window.sbSetIcons(bool)`; своего переключения `.sb-icons` не писать. z-index кнопки
  502 — между ручкой (501) и слоем перетаскивания (9999).
- Поиск по меню — ФИЛЬТР самого меню, не выпадающий список и не клоны ссылок: бейджи-поллеры ищут
  ссылку по `href`, у клона их нет. Прятать — класс `.sb-f-off` на `a.sb-link` или его `.mp-row`,
  не `style.display` (его держит `sbPermGroups()` для прав ролей). Исходная подпись — `data-sbf-txt`.
- ⌘K / Ctrl+K — только общий обработчик в `sidebar.js` (`window.sbFocusSearch()`); на страницах это
  сочетание НЕ занимать. Поиск по списку страницы — клавиша «/». На Mac — только ⌘.
- У каждого пункта `MENU` свой значок: перед добавлением пункта проверь, что значок в MENU ещё не
  занят (скрипт `tools/check_menu_icons.js` из патча); нет подходящего — Lucide в спрайт + `ICONS_V`.
- Новое сочетание клавиш на странице — строкой в `HOTKEYS` (`sb-profile.js`, окно «Быстрые клавиши»):
  иначе справочник врёт. Формат: `[клавиши с Mod/Alt/Shift, действие, где, href раздела или '']`.
