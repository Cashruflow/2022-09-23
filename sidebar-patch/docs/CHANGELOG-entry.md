## Сайдбар портала: кнопка «свернуть», поиск-фильтр по ⌘K/Ctrl K, уникальные значки, «Быстрые клавиши» (02.10.2026, ADR-309)
- `sb-resize.js?v=4`: кнопка `#sb-collapse` на границе меню (`i-chevrons-left/right`, `aria-expanded`), клик = двойной щелчок по границе, ширина восстанавливается; скрыта ≤768px. `window.sbSetIcons()`/`sbIsIcons()`, событие `sb:icons`.
- `sidebar.js`: ⌘K (Mac) / Ctrl+K (остальные) на всех страницах портала — фокус в поиск, меню разворачивается из колонки иконок, на телефоне открывается шторка; бейдж сочетания в поле. Поиск — фильтр самого меню вместо выпадающего списка: регистр, ё=е, другая раскладка, совпадение по пункту или группе, `<mark>`, ↑/↓/Enter/Esc, «Ничего не найдено», учёт «Быстрого доступа» и прав ролей. `.sb-search-results` удалён (`mhead.js?v=10`).
- `issues_page.js`, `ticket_page.js`: локальный Ctrl/⌘+K убран (дублировал «/»).
- Уникальные значки у всех 76 пунктов меню: 38 замен, 31 новый символ Lucide в `assets/icons.svg`, `ICONS_V` 13, `habits-sw.js` SHELL `?v=13` / `habits-v107`.
- `sb-profile.js?v=5`: пункт «Быстрые клавиши» (`i-keyboard`) — окно `uiInfo()` со списком всех сочетаний платформы (⌘ на Mac, Ctrl иначе), разделы, закрытые ролью, скрыты; `window.cfShowHotkeys()`.
