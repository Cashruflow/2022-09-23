# ADR-309: Сайдбар портала на ПК: кнопка свернуть/развернуть, поиск-фильтр по ⌘K/Ctrl K, уникальные значки пунктов, окно «Быстрые клавиши»

> Номер предложен по `docs/architecture/INDEX.md` (последний — ADR-308; ADR-287 в индексе отсутствует).
> Настоящий номер выдаёт `create_adr` — если он другой, заменить `ADR-309` в комментариях кода (поиск по `ADR-309`).

## Контекст

1. **Свернуть меню можно было только «по секрету».** Колонка иконок (64px, `sb-resize.js`) включалась
   двойным щелчком по невидимой границе или протаскиванием её влево. Ни подсказки, ни кнопки.
2. **Поиск по меню жил выпадающим списком из 10 клонов-ссылок** поверх «Быстрого доступа».
   У клонов не было бейджей (поллеры ищут оригинал по `href`), закреплённые пункты не учитывались,
   ошибка раскладки («kbls» вместо «лиды») и «ё» не находились.
3. **Ctrl/⌘+K вёл себя по-разному:** на `/issues` и `/ticket` — фокус в локальный поиск списка,
   на остальных страницах — поиск браузера.
4. **Значки повторялись:** из 76 пунктов MENU 22 значка встречались по 2–5 раз
   (`zap`, `tracking`, `structure` ×5, `clients`, `message` ×4, `search`, `fields` ×3, …).
   В режиме иконок пункты были неразличимы.
5. **Нигде не было списка хоткеев** — сочетания разбросаны по 20+ файлам.

## Решение

### 1. Кнопка «свернуть/развернуть» (`sb-resize.js` v4)
- `div#sb-collapse` (кружок-подложка 26px на токенах `--ui-bg`/`--ui-line`/`--ui-shadow-sm`) +
  внутри голая `button.ibtn` (вид — роль `btnCss()`, своего фона кнопке не пишем). Стоит НА границе:
  `left: calc(var(--sb-w) - 13px)`, `top: 24px`, `z-index: 502` — выше ручки `#sb-resizer` (501),
  ниже слоя перетаскивания (9999). Тянуть границу можно выше и ниже кнопки; `pointerdown` по кнопке
  не всплывает.
- Клик = двойной щелчок по границе: `setIcons(!icons); apply(true)` — прежняя ширина (`lastW`)
  возвращается, состояние пишется в `cf-sb-icons`. Значок `i-chevrons-left` / `i-chevrons-right`,
  `aria-label`/`title` «Свернуть меню»/«Развернуть меню», `aria-expanded`, `aria-controls="app-sidebar"`.
- Скрыта ≤768px (там шторка) и на экране входа (`body.sb-authwall`). Ширина колонки иконок — 64px, как была.
- Наружу: `window.sbSetIcons(bool)`, `window.sbIsIcons()`; событие `sb:icons` (`detail.icons`) — только
  на смену режима.

### 2. ⌘K / Ctrl+K — одно поведение на всех страницах портала (`sidebar.js`)
- Слушатель на `window` в фазе перехвата: на Mac — только ⌘ (Ctrl+K там «удалить до конца строки»
  в полях), иначе Ctrl; по `e.code === 'KeyK'` — работает в русской раскладке.
- `window.sbFocusSearch()`: из колонки иконок разворачивает меню (`sbSetIcons(false)`), на телефоне
  открывает шторку, ставит фокус и выделяет текст.
- Локальные Ctrl+K на `/issues` (`issues_page.js`) и `/ticket` (`ticket_page.js`) делали ровно то же,
  что «/» — фокус в поиск списка. Уникального действия нет — удалены; «/» остался.
- Бейдж в поле: `⌘K` на Mac, `Ctrl K` иначе; виден, пока поле пустое и без фокуса; на телефоне скрыт.

### 3. Поиск — фильтр самого меню
- `toLowerCase` + `ё→е`; запрос пробуется как есть и в другой раскладке (qwerty↔йцукен в обе стороны).
- Совпадение по подписи пункта или названию группы (совпала группа — видны все её пункты, в том
  числе закреплённые в «Быстром доступе»: группа пункта берётся из MENU по `href`).
- Несовпавшие строки прячутся классом `.sb-f-off` на `a.sb-link` или его обёртке `.mp-row`
  (menu-pins.js) — без клонов, бейджи остаются на месте. Пустые группы и пустой «Быстрый доступ»
  прячутся с заголовками. Свёрнутые группы на время поиска раскрываются и сворачиваются обратно
  при очистке (`data-sbf-was`).
- Подсветка — `<mark>` в `.sb-lbl` (и в названии группы); исходный текст хранится в `data-sbf-txt`.
- ↑/↓ — выделение `.sb-f-hi` по видимым строкам (первая выделена сразу), Enter — переход,
  Esc — очистка, второй Esc — выход из поля. «Ничего не найдено» — строкой внутри `.sb-nav`.
- Пункты закрытых ролью разделов (ADR-263) не считаются. Уход в колонку иконок сбрасывает фильтр.
- `.sb-search-results` удалён; `mhead.js` (v10) больше на него не ссылается. В `page-header.js`
  селектор в `SKIP` оставлен — он безвреден, а правка потянула бы бамп `?v=` в `cab-sidebar.js` и SW.

### 4. Уникальные значки
- Все 76 пунктов MENU — разные значки. 38 замен (таблица — README патча), из них 31 новый символ
  Lucide (lucide-static 1.50.0, ISC) в `assets/icons.svg` в формате существующих символов;
  `ICONS_V` 12 → 13 (`server.js`) и `habits-sw.js` SHELL `?v=13` + `CACHE` `habits-v107`.
- Правило: новый пункт MENU получает значок, которого ещё нет в MENU (проверка — README, скрипт).

### 5. «Быстрые клавиши» в меню профиля (`sb-profile.js` v5)
- Строка с `i-keyboard` для любой роли портала (владелец и сотрудник). Окно — общий `uiInfo()`
  (`ui-dialogs.js`, шторка `.mdl-*`, ADR-231/033), таблица «сочетание — действие — где»; `Mod` = ⌘ на Mac,
  Ctrl иначе. Сочетания закрытых роли разделов скрыты (`CF_PERM_DENY`).
- Справочник — массив `HOTKEYS` в `sb-profile.js`; `window.cfShowHotkeys()` — ручка для кабинета
  (`cab-foot.js`), который `sb-profile.js` пока не грузит (ADR-217).

## Проверка

- `node --check` всех изменённых JS; `patch -p1 --dry-run` всего диффа.
- Локальный прогон в jsdom: фильтр («лиды», «kbls», «ыщкшс», «справ» с `<mark>`, «финансы» по группе,
  «Ничего не найдено»), восстановление свёрнутой группы, ↑/↓, Ctrl+K из режима иконок, кнопка и
  восстановление ширины 230px, окно «Быстрые клавиши» с фильтром по правам.
- В браузере (Константин): 1440 и 390, тёмная и светлая темы, режим иконок, мобильная шторка,
  перетаскивание границы рядом с кнопкой, Ctrl/⌘+K на /issues, /ticket, /crm/chats (в поле ввода).

## Последствия

- Свернуть меню видно и можно одним кликом; ⌘K/Ctrl K — общий вход в любой раздел.
- Поиск больше не перекрывает «Быстрый доступ» и учитывает закреплённые пункты и бейджи.
- Значки различимы в колонке иконок. Цена — +31 символ в спрайте (≈ +10 КБ до gzip).
- Справочник хоткеев ведётся руками: новое сочетание без строки в `HOTKEYS` — окно врёт.
  Зафиксировано правилом в `docs/rules/ui.md`.
- На /issues и /ticket Ctrl+K теперь ищет по меню, а не по списку (список — «/»).
- Кабинеты клиентов (`cab-sidebar.js`) не затронуты: там свой сайдбар без поля поиска.
