# Доска вариантов: меню платформы

Исходники доски Claude Design (артборды `.dc.html` + раскладка `canvas.json`).

| Файл | Что показывает |
|---|---|
| `Sejchas.dc.html` | Как меню выглядит сегодня (`sidebar.js`): 8 групп, 58 пунктов |
| `VariantA.dc.html` | Вариант А — перенос референса: переключатель пространства, разделы цветными метками |
| `Main.dc.html` | Вариант Б — избранное и каталог (ведущий) |
| `VariantV.dc.html` | Вариант В — рельс значков + панель одной группы |
| `VariantG.dc.html` | Вариант Г — постоянного меню нет, навигация через ⌘K |
| `Support.dc.html` | Шторка «Поддержка»: чат, жалоба, доработка, 5 обращений в сутки |
| `Profile.dc.html` | Три набора пунктов для меню профиля (⋮) |
| `Rail.dc.html` | Механика: свёртывание в рельс и шторка на телефоне |
| `Context.dc.html` | Механика: настройка раздела правым кликом |
| `Status.dc.html` | Механика: статус на аватаре и как его видит клиент |

Токены взяты из живой платформы: `/theme.css` (`#0a0a0a`, `#141414`, `#00a0ff`,
скругление 8px), размеры меню — `--ui-nav-*` из `docs/DESIGN-TOKENS.md`,
иконки — реальные пути из `/assets/icons.svg`, логотип — `/assets/logo.svg`.

## Сборка

Артборды собираются из `*.src.html` подстановкой общих кусков:

    node build.mjs     # *.src.html + style.frag + logo.frag + icons.json -> *.dc.html

`menu-platformy.html` — собранная доска (страница с редактором внутри),
её пересобирает `seed-canvas.mjs` из навыка design. Руками не править:
править `*.src.html`, потом пересобирать.
