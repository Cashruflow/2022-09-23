# Паттерны адаптивной карточки

Примеры переиспользования базовой карточки (job-card.css) для разных типов контента. Каждый файл содержит 4 экземпляра карточки: 3 в сетке и 1 в узком сайдбаре 280px.

## Таблица паттернов

| Файл | Назначение | Что изменено | Цвета |
|------|-----------|-------------|-------|
| **service.html** | Карточка услуги компании | Компания, категория «Под ключ», название услуги, локация с акцентом (вся РФ). Дополнено: цена и срок запуска. Бэдж с процентом и информацией о повторных клиентах. | Primary: #e8590c (оранжевый), Highlight: #fff4e6, Radius: 16px |
| **tariff.html** | Тариф подписки | Название тарифа как компания, цена/месяц как основной текст, лимиты как локация. Удалён логотип компании (заменён значком). Кнопки: поделиться и в избранное. Бэдж с меткой «Хит» + « популярный». | Primary: #4285f4 (синий), Highlight: #e8f0fe, Radius: 12px |
| **review.html** | Отзыв клиента | Имя клиента, роль, цитата-отзыв как основной текст, город как локация, дата публикации, звёзды в деталях. Аватар клиента в бэджде с меткой «5★» + « проверенный». Кнопки: поделиться и в избранное. | Primary: #34a853 (зелёный), Highlight: #e6f4ea, Radius: 14px |
| **vacancy.html** | Вакансия (на русском) | Копия базовой demo.html с локализацией на русский: названия кнопок, метка совпадения, текст деталей. Уровень должности, локация с Remote опцией. | Primary: #9c27b0 (фиолетовый), Highlight: #f3e5f5, Radius: 16px |

## Использование

Каждый файл импортирует `../../../card/job-card.css` и переопределяет только custom properties (--jc-color-primary, --jc-color-highlight, --jc-radius) на оболочке `.job-card`. Никакие новые CSS классы не добавлены.

Для использования на лендинге скопируйте структуру `<article class="job-card">` и переопределите токены на нужные для бренда значения.

## Что общего с базовой карточкой

- Все элементы остаются: `__logo`, `__company`, `__level`, `__role`, `__location`, `__accent`, `__details`, `__muted`, `__footer`, `__badge`, `__avatar`, `__badge-text`, `__badge-label`, `__btn`
- Поддержка контейнер-запросов (@container) — карточка адаптируется к ширине контейнера, не экрана
- SVG иконки для кнопок (поделиться, закладки) встроены в разметку
- Аватары и логотипы — inline data:image/svg+xml
