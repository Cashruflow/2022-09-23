# Чеклист перед запуском adaptive card

## Подключение

- [ ] CSS подключён один раз (не дублируется на разных страницах) — в `<head>` или через критичный CSS
- [ ] Классы `.job-card*` не конфликтуют с вашей темой (`.card`, `.footer`, `.badge` на сайте) — поищите в DevTools
- [ ] Шрифт наследуется от сайта или переопределён `--jc-font` в контексте карточки — консоль: `getComputedStyle(document.querySelector('.job-card')).fontFamily`
- [ ] Цветовые токены (`--jc-color-*`) установлены на контейнере карточки или выше — добавьте в `.job-card { --jc-color-primary: … }`

## Контент

- [ ] Длинные названия (роль, услуга, локация) не выходят за границы на 320px — оберните их в span и проверьте `overflow-wrap`
- [ ] Необязательные блоки (уровень, детали, бейдж) пусты, если данные не передали — не должны показываться пустые теги
- [ ] Логотип — реальное изображение с атрибутами `width` и `height` (не только в CSS) — страница загружается без прыжков (CLS)
- [ ] Аватар в бейдже имеет `width="40"` и `height="40"` с `object-fit: cover` — проверьте в инспекторе
- [ ] Текст внутри бейджа-аксента — короткий (≤ 5 символов, например «98%», «Хит», «5★»), длинный текст попадает в `.job-card__badge-label` — в узком/≤400px режиме лейбл скрывается, и длинный текст обрезается с многоточием

## Адаптация

- [ ] На ширине 320px логотип по центру, половина над карточкой — DevTools: ≤320px ширина экрана
- [ ] На 390px карточка в широком режиме (358px) — логотип право-вверху, текст слева, бейдж только % (лейбл нужен ≥400px) — Chrome: Pixel 5
- [ ] На 768px+ карточка в режиме и число колонок — см. devices.md; логотип в углу, текст слева — DevTools: планшет
- [ ] На 1280–1920px режим и число колонок — см. devices.md, без горизонтального скрола — Desktop view
- [ ] В сайдбаре 280px карточка не ломается, логотип по центру, нет скрола вправо — DevTools width: 280px
- [ ] Логотип в узком режиме не обрезается сверху (`margin-top` учтена) — родитель с `overflow:hidden` (слайдер, модалка)

## Доступность

- [ ] Кнопки (поделиться, сохранить) имеют `aria-label="…"` — скринридер читает цель кнопки
- [ ] Все кнопки имеют `type="button"` (не просто `<button>`) — не срабатывают как submit внутри формы
- [ ] При нажатии Tab фокус виден на кнопках (`:focus-visible` с outline) — проверьте любой браузер + Tab
- [ ] Контраст `--jc-color-muted` (#5f6368) на `--jc-color-bg` (белый) ≥4.5:1 — при своих цветах проверьте WebAIM
- [ ] Заголовки структурированы: одна роль в `<h*>`, остальное в `<p>` или `<span>` — валидность в WebAIM WAVE

## Производительность

- [ ] Нет иконочных шрифтов (Material Icons, FontAwesome) — только inline SVG в атрибутах или `<svg>`
- [ ] Логотип и аватар сжаты (JPEG ≤50KB, PNG ≤30KB, SVG ≤5KB) — ImageOptim, TinyPNG
- [ ] Нет CLS на загрузке (изображения имеют `width`/`height` заранее) — PageSpeed Insights: CLS < 0.1

## Браузеры

- [ ] Safari 16+ — container queries поддерживаются, карточка адаптируется правильно
- [ ] Chrome/Edge 105+ — container queries работают, ширина контейнера измеряется верно
- [ ] Firefox 110+ — `@container` и единицы `cqi` поддерживаются
- [ ] Старше (Safari <16, Chrome <105) — карточка остаётся в узком режиме, не ломается (graceful degradation)

---

## Быстрая проверка за 2 минуты

1. **Не обрезается ли логотип сверху в узком режиме?** — Откройте DevTools, установите ширину 300px, посмотрите на половину логотипа над карточкой
2. **Есть ли `width`/`height` у логотипа и аватара?** — Инспектор → найдите `<img>` → должны быть атрибуты (не только в CSS)
3. **Кнопки видны с фокусом при Tab?** — Нажимайте Tab в любом браузере, каждая кнопка должна светиться outline'ом
4. **Контраст текста нормальный на вашем фоне?** — WebAIM Contrast Checker: `--jc-color-muted` на `--jc-color-bg` ≥4.5:1
5. **Нет горизонтального скрола при 320px?** — DevTools: ширина 320px, оставляем 16px гутер, карточка ≤288px, все влезает
