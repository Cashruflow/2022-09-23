# Адаптивные карточки (ПК → мобильный)

Карточка перестраивается по ширине своего контейнера с помощью @container. Узкий режим работает на ширине карточки менее 340px, широкий режим — 340px и выше, подпись в бейдже появляется при ширине 400px и более.

## Справочники и чек-листы

- [rules.md](rules.md) — 23 правила: почему / плохо / хорошо
- [devices.md](devices.md) — Телефон 320/390, планшет 768, ноутбук 1280, экран 1920, сайдбар 280 — замеры и скриншоты
- [checklist.md](checklist.md) — Проверка перед вставкой, экспресс-проверка за 2 минуты
- [patterns/](patterns/README.md) — Услуга, тариф, отзыв, вакансия
- [screenshots/](screenshots/) — Демонстрационные скриншоты всех устройств

## Как посмотреть HTML-примеры

GitHub показывает `.html` как код — скачайте файл вместе с папкой `card/` и откройте в браузере. Пути к CSS относительные, поэтому структура папок должна быть сохранена.
