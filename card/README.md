# Адаптивная карточка (ПК → мобильный)

Источник: карусель frontendjoe «React Cards Part 09». Код распознан со скриншотов
и лежит как есть в `original/`. Рабочая версия — `job-card.css` + `JobCard.jsx` (React)
или разметка из `demo.html` (чистый HTML, для лендингов без React).

| Файл | Что это |
|---|---|
| `original/Card.jsx`, `original/Card.css` | Оригинал со скриншотов, без правок |
| `job-card.css` | Исправленные стили: изоляция, container queries, токены |
| `JobCard.jsx` | React-компонент на этих стилях |
| `demo.html` | Демо без сборки: сетка лендинга, узкий виджет, брендирование |

## Как работает адаптация

- **Узко (< 340px ширины карточки):** логотип по центру и наполовину над карточкой,
  текст по центру, у бейджа видны только проценты.
- **Широко (≥ 340px):** логотип в правом верхнем углу, текст слева.
- **От 400px:** у бейджа появляется подпись «profile match».

Размеры шрифтов плавно меняются через `clamp()`.

## Разбор оригинала: что мешает использовать его как есть

| # | Проблема в оригинале | Чем грозит | Что сделано |
|---|---|---|---|
| 1 | Глобальные селекторы `em`, `h2`–`h5`, `:is(h2,h3,h4,h5)` | Меняют все заголовки и курсив на лендинге | Все стили под `.job-card__*` |
| 2 | Общие классы `.card`, `.main`, `.footer`, `.badge`, `.details` | Конфликтуют с Bootstrap/Tilda/темой сайта (например, `.footer` сайта) | Классы по БЭМ с префиксом `job-card` |
| 3 | `@media (width >= 430px)` — считает ширину **экрана** | В сайдбаре или виджете на ПК карточка узкая, но включается «широкий» режим, и вёрстка ломается | `@container`: адаптация по ширине самой карточки |
| 4 | `width: clamp(200px, 80vw, 500px)` | В колонке уже 80vw карточка вылезает; в сетке не тянется на всю ячейку | `width: 100%; max-width` (токен `--jc-max-width`) |
| 5 | Логотип висит на `top:0; translate -50%`, отступа сверху нет | Верх логотипа обрезается у родителя с `overflow:hidden` (слайдеры, модалки) | `margin-top` под половину логотипа в узком режиме |
| 6 | `import logo from "./logo.svg"` жёстко внутри компонента | У всех карточек один и тот же логотип | `logo` передаётся пропсом |
| 7 | `<button>` без `type` и подписи, иконка — текст шрифта Material | Внутри `<form>` кнопка отправляет форму; скринридер читает «share»; пока шрифт грузится, видно слово «bookmark» | `type="button"`, `aria-label`, inline SVG без внешнего шрифта |
| 8 | `h2`/`h3`/`h4`/`h5` подряд | Ломает структуру заголовков страницы (SEO и доступность) | Один заголовок (роль, `headingLevel` настраивается), остальное — `<p>` |
| 9 | `<img>` без `width`/`height`, аватар без размеров и `object-fit` | Контент прыгает при загрузке (CLS в PageSpeed), аватар растягивается | Размеры и `object-fit` заданы |
| 10 | `:hover` без проверки устройства | На телефоне фон кнопки «залипает» после тапа | `@media (hover: hover)`, плюс `:focus-visible` для клавиатуры |
| 11 | Нет переноса длинных строк | Длинная должность или услуга распирает карточку на 320px | `overflow-wrap: anywhere`, `flex-wrap` у строки деталей |
| 12 | Мусор: `{" "}` в зарплате, пробелы в `<em> 64% </em>`, у `.badge p` не сброшен `margin` | Лишние отступы | Убрано |
| 13 | Цвета зашиты, нет `font-family` | Под бренд придётся править CSS | Токены `--jc-*`, шрифт наследуется от сайта |

**Что в оригинале хорошо и сохранено:** `clamp()` для шрифтов, CSS-переменные для цветов,
`aspect-ratio` у логотипа, компактная разметка.

## Использование

### Лендинг (без React)

```html
<link rel="stylesheet" href="job-card.css">
<!-- разметка карточки — из <template> в demo.html -->
```

Карточки в сетке:

```css
.cards { display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 24px; }
```

Брендирование — только через токены, сам CSS не трогаем:

```css
.my-landing .job-card {
  --jc-color-primary: #e8590c;
  --jc-color-highlight: #fff4e6;
  --jc-radius: 16px;
  --jc-font: "Poppins", sans-serif;
}
```

### React / виджет платформы

```jsx
<JobCard
  logo="/img/yandex-direct.svg"
  company="Digital CashFlow"
  level="Под ключ"
  role="Настройка Яндекс.Директа"
  location="Онлайн"
  isRemote remoteLabel="(вся РФ)"
  salary="от 30 000 ₽" salarySuffix=""
  when="запуск за 3 дня"
  profileMatch={98} matchLabel="клиентов продлевают"
  onShare={share} onSave={save} saved={isSaved}
  shareLabel="Поделиться" saveLabel="В избранное"
/>
```

Необязательные блоки (уровень, детали, бейдж, кнопки) не выводятся, если не передать
соответствующие пропсы. Поэтому ту же карточку можно использовать для услуги, тарифа
или отзыва.

## Совместимость

Container queries и единицы `cqi` поддерживаются в Chrome/Edge 105+, Safari 16+
и Firefox 110+. В более старых браузерах карточка остаётся в узком режиме
(логотип по центру) и не ломается.
