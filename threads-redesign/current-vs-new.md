# /threads — сейчас → в макете

Источник текущей страницы (сервер, только чтение): `web/public/threads.html`, `web/public/threads-analytics-widget.js`, `web/threads.js` (роут `/threads` и `/api/threads/*`), пункт меню — `sidebar.js` (группа «Интеграции», «Тредс»).
Функции и API не меняются. Экраны макета: `?screen=posts|keywords|analytics|states`, `&view=desktop|mobile&theme=light|dark`; PNG — `node render.mjs`.

Стиль: каркас `/analytics` (`seo-v2.css`) — плавающий рейл слева, карточки радиус 18 с мягкой тенью в светлой теме, iOS-сегмент вкладок, кнопки-пилюли; лента постов в духе Threads; на телефоне — крупный заголовок в духе One UI.

## Что потребует переноса в код
1. **Только `threads.html` + `threads-analytics-widget.js`** — разметка и CSS; JS-логика (`refreshStatus`, `compressImage`, очередь `/insights`, `showTab`, `noInsights`) остаётся, меняются шаблоны строк в `loadPosts`/`doSearch`/`cardHtml`. Виджет аналитики подключён и в других местах — поднять `?v=` везде.
2. **@username** — уже отдаёт `/api/threads/status` (`live.username`), сейчас страница его не показывает; в макете он в капсуле статуса и в «Новом посте». Сервер не меняется.
   **Склонение счётчиков** — функция `plural(n, ['лайк','лайка','лайков'])` (в `threads.html` макета) переносится в шаблон строки статистики в `loadPosts`; формы: просмотр/лайк/ответ/репост/цитата.
3. **Подписи дней под столбиками** — данные есть (`d.days[].day`), сейчас только в `<title>`.
4. **Иконки — нужно добавить в `web/public/assets/icons.svg`:** `i-heart`, `i-repeat-2`, `i-menu`, `i-calendar`, `i-clock`, `i-zap` (Lucide; в макете они уже лежат во встроенном спрайте — `<symbol>` можно скопировать оттуда) и поднять `?v=` спрайта во всех подключениях; остальные (`i-eye`, `i-message`, `i-text-quote`, `i-image`, `i-send`, `i-external-link`, `i-refresh`, `i-link`, `i-chart`, `i-newspaper`, `i-circle-alert`, `i-circle-check`, `i-info`, `i-close`) уже есть в спрайте.
5. **Токены:** `--th-radius` 18 / `--th-row-radius` 14 (литералы `.sv2-*`), `--th-av-l`; завести через `/set` + `THEME_DEFAULTS` или оставить литералами в `seo-v2.css`. Мягкий danger-тон (`color-mix` 8/24%) — аналога `--ui-danger-soft` нет.
6. Капсула статуса и сегмент вкладок — в шапку страницы (`page-header.js` собирает её из `<h1>` + `.ph-s`; нужен слот действий справа или своя разметка `.sv2-top`).
7. Мобильное: кнопки ⚙/☰ — существующие `mhead.js`/`sidebar.js`, нижней панели нет (не добавлялась).
8. **ПК, «Мои посты»:** сетка `1fr | 408px`, справа только «Новый пост» (липкая колонка); карточка «Аккаунт» убрана.
