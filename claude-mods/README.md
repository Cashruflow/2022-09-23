# Моды Claude Code

## context-bar

Полоска контекста с разбивкой по типу: системный промпт, инструменты, MCP, файлы, диалог, свободно.

- терминал и десктоп: полоса над полем ввода;
- везде (включая мобильное приложение): команда `/ctx` и строка статуса «Контекст 164k/200k · 82%».

Установить:

```
/plugin install context-bar --marketplace cashruflow/2022-09-23
```
