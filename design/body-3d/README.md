# Состав тела 3D — «до / после»

Макет карточки для медкарты (ai.cashruflow.ru → Медкарта → Профиль), рядом с
существующими «Состав тела» и «Состав по зонам».

Фигура — человек **в профиль**: живот выступает вперёд, и в фас это направление
совпадает с направлением взгляда, поэтому выпуклость не читается ни при каком её
размере. Артборд `Angles.dc.html` показывает это на пяти углах.

Тело собирается из обобщённых цилиндров (торс и голова — стопки суперэллиптических
сечений, конечности — трубы по сплайну), проецируется ортографически и
растеризуется в маску; контур снимается marching squares и сглаживается. Детали
рисуются послойно от дальней к ближней, поэтому дальняя рука не просвечивает
сквозь корпус.

Главный приём: **эталонное тело на «до» и «после» одно и то же** — тело при 15 %
жира. Меняется только живот. **Одна точка = 20 г** жира сверх нормы, так что число
точек — это сама величина избытка. Весь избыток сведён в живот: разбивка по рукам
и ногам остаётся в карточке «Состав по зонам».

## Файлы

| Файл | Что |
|---|---|
| `gen.mjs` | геометрия тела, проекция, генерация SVG |
| `build.mjs` | данные образца, вёрстка карточек, сборка артбордов |
| `Main.dc.html` | основной макет: «до» и «после» рядом |
| `Mobile.dc.html` | тот же макет на ширине телефона |
| `Angles.dc.html` | пять углов — почему фигура в профиль |
| `Scale.dc.html` | шкала 0…15 кг: как растёт живот |
| `canvas.json` | раскладка артбордов на канве |

Пересборка: `node build.mjs`.

Цифры в макете — **образец** по формату бланка DDX/InBody, а не реальные замеры.
