# Состав тела 3D — «до / после»

Макет карточки для медкарты (ai.cashruflow.ru → Медкарта → Профиль), рядом с
существующими «Состав тела» и «Состав по зонам».

Фигура человека рисуется контурами (кольца поверхности + продольные линии,
ортографическая проекция — та же математика, что у глобуса в разделе «Жизнь»),
жир сверх нормы — точками.

Главный приём: **эталонное тело на «до» и «после» одно и то же** — тело при 15 %
жира. Меняется только облако точек, поэтому разницу видно раньше, чем прочитаешь
цифры. **Одна точка = 20 г** жира сверх нормы, так что число точек — это сама
величина избытка, а не украшение.

Толщина облака по зонам считается как масса, делённая на площадь зоны — тем же
правилом, что ореол в виджете «Состав по зонам» (`medcard_profile.js`, `segGlow`),
и по тем же площадям (`SEGAREA`). Абсолютный масштаб увеличен: настоящие 8 мм
подкожного жира дали бы на фигуре высотой 490 px два пикселя.

## Файлы

| Файл | Что |
|---|---|
| `gen.mjs` | геометрия тела, проекция, генерация SVG |
| `build.mjs` | данные образца, вёрстка карточек, сборка артбордов |
| `Main.dc.html` | основной макет: «до» и «после» рядом |
| `Mobile.dc.html` | тот же макет на ширине телефона |
| `Angles.dc.html` | одна фигура с пяти сторон — проверка объёма |
| `DotBody.dc.html` | вариант A: тело тоже точками |
| `ZoneMesh.dc.html` | вариант B: кольца красит вердикт зоны с бланка |
| `canvas.json` | раскладка артбордов на канве |

Пересборка: `node build.mjs`.

Цифры в макете — **образец** по формату бланка DDX/InBody, а не реальные замеры.
