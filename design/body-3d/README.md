# Состав тела 3D — «до / после»

Макет карточки для медкарты (ai.cashruflow.ru → Медкарта → Профиль), рядом с
существующими «Состав тела» и «Состав по зонам».

Модель точечная, как шар в разделе «Жизнь»: узлы стоят регулярной сеткой по
поверхности тела, дальняя сторона тусклее, фигура считается и поворачивается на
любой угол. Поза как на бланке DDX — руки отведены на 30°, иначе бока и сами
руки закрыты корпусом.

Узел лежит на поверхности тела **со слоем жира**, поэтому живот виден
выпуклостью. **Цвет узла** — толщина слоя под ним: от холодного (слоя нет) до
янтарного. Пунктиром внутри — то же тело при 15 % жира.

Толщина слоя в зоне = масса зоны, делённая на её площадь, — тем же правилом, что
ореол в виджете «Состав по зонам» (`medcard_profile.js`, `segGlow`), и по тем же
площадям `SEGAREA`. Внутри торса слой распределён неравномерно: спереди толще
всего, по бокам «ушки», спина почти чистая.

Тело собирается из обобщённых цилиндров (торс и голова — стопки суперэллиптических
сечений, конечности — трубы по сплайну), проецируется ортографически и
растеризуется в маску; контур снимается marching squares и сглаживается.

## Файлы

| Файл | Что |
|---|---|
| `gen.mjs` | геометрия тела, проекция, генерация SVG |
| `build.mjs` | данные образца, вёрстка карточек, сборка артбордов |
| `Main.dc.html` | основной макет: «до» и «после» рядом |
| `Mobile.dc.html` | тот же макет на ширине телефона |
| `Angles.dc.html` | пять углов разворота |
| `Scale.dc.html` | шкала 0…15 кг |
| `Compare.dc.html` | текущий виджет «Состав по зонам» рядом с новым |
| `canvas.json` | раскладка артбордов на канве |

Пересборка: `node build.mjs`.

Цифры в макете — **образец** по формату бланка DDX/InBody, а не реальные замеры.
