Вёрстка medcard_habits.js · missionCard()ui.css · .hab-card
  • Блок «Сегодня» числами: сделано / из плана / осталось. Данные уже приходят — met.today_fact, met.today_plan.

  • Темп печатать как «137 раз в день при плане 120 · +14%» из actual_daily_rate / planned_daily_rate, а не голое +14. Подпись — окно усреднения (7 дней при сроке ≤30, иначе 30 — habit_engine.js:90).

  • Кольцо «сегодня» с датой в центре убрать: оно занимает 84px и не отвечает ни на один вопрос, на который отвечают числа выше. Кольцо цели остаётся.
  • Карточка становится выше — в сетке minmax(440px,1fr) при ≥900px это не ломает раскладку, на мобиле колонка одна.

Сервер

Логикаhabits.js:663
  • Окно правки для записей текущего дня — до конца дня вместо 30 минут (RESULT_EDIT_WINDOW_MS). Ошибку замечают, когда открывают карточку, а не через 5 минут после ввода.
  • Для прошлых дней — корректирующая запись со знаком минус вместо отказа. История честная, сумма чинится, аудит цел.
  • Оба изменения — решение Константина, не вёрстка: тут только предложение.

Соседние страницы и /set

Общее
  • «исправить» сейчас — крашеный span с onclick. Канон платформы — .tbtn / .ibtn (ADR-069): их вид и зона тапа приезжают из /set → «Кнопки».
  • Компонент «Сводка» держит литеральные цвета (сознательно — он всегда тёмный). Значит акцент аккаунта из /set → «Акцент» в статистику не доходит: либо завести для hero/плиток свои --ui-*, либо записать это правилом в ui.css, чтобы не «чинили» повторно.
  • Блок «Сегодня» и строка «последняя запись» — кандидаты в общие компоненты, как уже сделали place-field.js и .stats-*: то же самое просится во вкладку «Жизнь» и в «Дневник».
  • Все числа — font-variant-numeric: tabular-nums (в файле уже есть MONO): при обновлении цифры перестают дёргаться.
Значения в макетах — реальные для миссии «Отжимания»: 3 600 раз за 30 дней, план 120/день, минимум 60, набрано 2 640, темп 137/день за последние 7 дней. Числа сходятся между всеми артбордами.
