# Страница «Ai-агенты» — разбор и редизайн

Исходники дизайн-канвы «до и после» для страницы `/agents` портала Digital CashFlow
(`ai.cashruflow.ru`). Кода портала здесь нет — только макеты.

## Что это

Разбор текущей страницы и предложение по её переработке в существующей
дизайн-системе портала: токены `#00a0ff`, карточки `#141414 / #232323 / radius 14`,
сайдбар 230px — взяты из `web/public/ui.css`, `web/public/agents.html`
и `web/public/sidebar.js`. Данные в макетах — правдоподобный пример по реестру
из `web/agents.js` (6 агентов), не боевые цифры.

## Замечания к текущей странице

1. Нет ответа на «всё ли живо?» — статус только в 11px-бейджах, надо просканировать
   все шесть карточек, чтобы заметить обрыв канала.
2. Ошибка визуально весит столько же, сколько «в разработке».
3. Мета-строка — свалка: расписание вида `ежедневно 04:00 + вс 09:00 (крон)`
   и `kpi_cron.mjs` читаются как отладочный вывод.
4. Расход (токены, рубли) — самое ценное на странице — лежит в подвале карточки
   сплошной строкой, цифры разных агентов не сравнить глазом.
5. `agents.html:130` — «2 прогонов»: плюрализация не сделана.
6. Кнопка запуска в самом низу карточки; у трёх агентов из шести её нет вовсе,
   и объяснение спрятано в `note` мелким серым.
7. Вкладки «Агенты» и «Чаты» не связаны: из карточки агента нельзя открыть его чат,
   роутер спрятан в `<select>`.
8. `spend.recent` (пять последних вызовов) считается в `agentSpend()`
   и не показывается нигде.

## Что предлагается в «После»

Полоса сводки (работают / требуют внимания / в разработке / расход сегодня);
блок «Требует внимания» наверху с полным текстом обрыва; карточка с иконкой-статусом,
расписанием-чипом и метриками в четыре выровненные колонки; спарклайн прогонов
за 7 дней; ряд действий «Запустить · Чат · Задача · Страница»; правая колонка
«Последняя активность» из уже считающегося `spend.recent`.

В блоке «Требует внимания» показана расшифровка симптома (403 = бан IP самого VPS
на границе Anthropic). Это знание уже лежит в `persona` агента `ai_health`
в `web/agents.js`, но на странице его сейчас нет — то есть это предложение,
а не описание существующего поведения.

## Статус

**Реализовано на портале 28.08.2026, версия 2.25.4.** Вариант Б (плотный реестр-таблица)
отклонён — решили делать не реестр; артборд оставлен как след решения.

Правки на портале (не в этом репозитории):

- `web/public/agents.html` — страница переписана: полоса сводки, секция «Требуют внимания»
  со сломанными агентами наверху, метрики в четыре выровненные колонки со спарклайном,
  колонка «Последняя активность», ряд действий «Запустить · Чат · Задача · Страница».
- `web/agents.js` — новое поле `spend.days` (прогоны по дням за неделю, ровно 7 точек
  включая нули) для спарклайна; расписания в реестре переписаны без служебных деталей.
- `docs/CHANGELOG.md`, `docs/VERSION.md` — запись об изменении.

Отличия реализации от макета — сознательные:

- Блок «Требует внимания» — это карточки сломанных агентов, поднятые в верхнюю секцию,
  а не отдельная плашка. В макете плашка содержала расшифровку симптома («403 = бан IP
  самого VPS»); в данных `/api/agents` такой расшифровки нет, она живёт только в `persona`
  агента `ai_health`, поэтому на страницу не вынесена — иначе это выдумка в интерфейсе.
- Правая панель «Спросить агента» добавлена 29.08.2026 (v2.36.2): вопрос уходит тем же
  `POST /api/agent-chat` с `agent_id:"router"`, что и вкладка «Чаты» с «Роутером» — сервер
  сам выбирает адресата, отвечает от его имени и пишет обе реплики в чат этого агента.
- В чипе расписания стоит реальная строка из реестра, а не сокращённая на фронте.

Ограничения проекта, из-за которых макет и код расходятся по мелочам: кнопкам нельзя
писать свой CSS (роли `.btn`/`.tbtn` из `/theme.css`, ADR-063), эмодзи в интерфейсе
запрещены (значки — из `/assets/icons.svg`), браузерный `alert()` заменён на `uiToast`
(ADR-033).
