# /structure на мобильном — макеты

Артборды Claude Design для мобильной версии раздела `/structure`
платформы cashruflow (`web/public/structure.html`).

Принятый вариант — **аккордеон**: всё дерево на одном экране, папки
раскрываются на месте, шеврон слева, шаг уровня 18px с направляющей линией.
Строка поиска сохранена и закреплена в шапке, действия с файлом переехали
в нижнюю шторку. Черновики варианта с проваливанием по папкам сняты
с холста, история — в PR #1.

- `build.mjs` — единственный источник вёрстки. Правим здесь, гоним `node build.mjs`,
  пересеиваем холст навыком `/design`.
- `*.dc.html` — сгенерированные артборды (не правим руками).
- `canvas.json` — раскладка холста и заметки.
- `structure-mobile.html` — собранный холст (пересобирается, в правках не участвует).

Источники, из которых снят вид:

- `web/public/structure.html` — палитра типов файлов, фоны, toast копирования.
- `web/public/sidebar.js` — кнопка меню 42×42 в правом верхнем углу, нижняя шторка,
  «ручка» шторки, группы списка.
- `web/server.js` → `THEME_DEFAULTS` / `/theme.css` — токены `/set`.
- `docs/structure-comments.json` — реальные подписи к папкам и файлам.
