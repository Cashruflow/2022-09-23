Правила

Как собирать шапку

Делаем

  • 01Заголовок и кнопки — одним flex-рядом, кнопки прижаты вправо.
  • 02Ровно один подзаголовок, ровно одна строка.
  • 03Счётчики и статистика — в подзаголовок, словами.
  • 04Кнопка действия — своим рядом под шапкой, слева.
  • 05Отбивка воздухом: 18px до контента.
  • 06Версия модуля — в строке с H1, по базовой линии.
  • 07Текст заголовка — название раздела как есть; длинный переносится на две строки.
  • 08Геометрия — только токены --ui-*.

Не делаем

  • 01Иконку или эмодзи слева от H1 — ни на одной странице.
  • 02Полосу-разделитель под шапкой.
  • 03Капс-киккер над заголовком («РАБОТА · ПРОЕКТЫ»).
  • 04Ссылку «← AI-платформа» — это дубль бургера.
  • 05Счётчик «(262)» внутри H1.
  • 06Абзац описания вместо подзаголовка.
  • 07position:fixed кнопки + распорку под них.
  • 08Кнопки-значки внутри текста H1 (как «+» в трекере).
  • 09Сокращать название раздела ради ширины.
Разметка — одна на все страницы
<!-- шапка страницы: единый компонент, копий на страницах нет -->
<header class="ph">
  <div class="ph-row">
    <div class="ph-ttl">
      <h1 class="ph-t">Доступы</h1>
      <span id="mvBadge-medcard"></span>  <!-- версия; нет модуля — нет узла -->
    </div>
    <div class="ph-act"></div>  <!-- сюда JS кладёт обновить + бургер -->
  </div>
  <p class="ph-s">22 доступа · 5 проектов</p>
</header>
/* ui.css — единственное место, где это описано */
.ph      { padding: 26px var(--ui-page-pad,44px) 0; }
.ph-row  { display: flex; align-items: center; justify-content: space-between;
            gap: 12px; min-height: 42px; }
.ph-ttl  { display: flex; align-items: baseline; gap: 10px; min-width: 0; }
.ph-t    { font-size: 34px; font-weight: 800; letter-spacing: -.02em;
            margin: 0; min-width: 0; color: var(--ui-tx,#fff);
            white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.ph-s    { font-size: 15.5px; font-weight: 500; margin: 4px 0 0;
            color: var(--ui-tx2,#8a8a93);
            white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
.ph-act  { display: flex; gap: 8px; flex: none; }
.ph + *  { margin-top: 18px; }   /* отбивка воздухом, не полосой */

@media (max-width: 768px) {
  .ph    { padding: 14px var(--ui-page-pad-m,14px) 0; }
  .ph-t  { font-size: 32px; }
  .ph-s  { font-size: 15px; }
}

NB

Одно отступление от текущей медкарты: её <h2 class="ph1-sub"> сейчас без font-size, то есть рисуется браузерным 24px. Под описания («Паспорт сайтов проекта…») это слишком крупно и съедает ровно ту высоту, на которую жалоба. В компоненте подзаголовок зафиксирован на 15px — значит, на медкарте строка «Профиль» станет мельче. Если оставляем 24px, компонент придётся делить на два вида.
