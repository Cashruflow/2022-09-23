## Что починено

Адверсариальное ревью нашло 22 воспроизведённые тестом поломки. Закрыты все 22:
`node --test bugs.test.mjs ok.test.mjs` → **35 из 35 зелёных** (было 13 из 35).

Самое опасное:

- **Мусор в `cf_pins_v1` больше не роняет сайдбар.** Нестроковые записи и адреса с `\`
  давали исключение наружу из `mount()`, обрывая `inject()` портала и `cab-sidebar.js`.
  Теперь набор чистится на входе (`clean()`), значение атрибута в селекторе экранируется
  и по слэшу тоже, а `querySelector` обёрнут в try/catch.
- **Шторка кабинета не захлопывается в момент закрепления.** Окно `suppressed()` в 500 мс
  заменено одноразовым флагом: он живёт до первого спросившего, а не N миллисекунд. Это же
  чинит обратную сторону — обычный тап сразу после удержания снова закрывает шторку.
- **Повторный `mount()` не дублирует меню** — отдаёт уже собранное (`root.__mpApi`).
- **Второй палец не закрепляет строку сам** — предыдущий таймер удержания гасится.
- **Перетаскивание завершается по `pointercancel`**, а не только по `pointerup`.
- **Открепление после перерисовки группы не теряет пункт** — проверяется `isConnected`.
- **Режим правки возвращает свёрнутые группы как было** и глушит переход по Enter
  (не только CSS-правилом `pointer-events`).
- **Приватный режим больше не врёт**: `writeAll()` возвращает успех, тост говорит правду.
- **Ручка перетаскивания — кнопка**, порядок меняется стрелками с клавиатуры.
- **`page-copy`:** `fetch(new URL(...))` не теряет адрес, `AbortError` не считается упавшим
  запросом, отказ `navigator.clipboard` откатывается на `execCommand` и возвращает фокус,
  многострочные ошибки и счётчик из `h1` не рвут markdown.

Два места, где поведение изменено осознанно, а не «починено»:

- Набор ограничен **50 закреплёнными**: `render()` ходит в DOM на каждую запись, и 10 000
  записей морозили монтирование на 822 мс. На 51-м приходит тост «больше некуда».
- При двух строках с **одинаковым href** (платформа такое запрещает, но защищаемся) двигается
  та строка, которую нажали: нажатая запоминается и предпочитается поиску по адресу.

## Тесты

`tests/` — харнесс и оба набора из ревью, плюс сам отчёт `ADVERSARIAL.md`.

```
cd tests && npm i jsdom && node --test --test-reporter=spec bugs.test.mjs ok.test.mjs
```

Харнесс поднимает разметку портала и кабинета в jsdom вместе с чужим кодом, который трогает
те же узлы (поллер бейджей, `sbToggleGroup`, оба закрывателя шторки), и синтезирует
указательные события — в jsdom ни `PointerEvent`, ни `matchMedia`, ни `localStorage` нет.
Таймеры настоящие: удержание ждёт реальные 600–1200 мс, поэтому прогон идёт ~7 секунд.
