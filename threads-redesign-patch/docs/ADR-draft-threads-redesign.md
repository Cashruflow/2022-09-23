# ADR-XXX: Редизайн страницы /threads — только вид

> Черновик. Создавать ТОЛЬКО через `create_adr` (номер выдаст инструмент), затем `migrate-ard` + `validate-ard`.
> Номер будущего ADR в код не вписан и вписываться не должен.

## Контекст

Страница `/threads` (`web/public/threads.html` + `threads-analytics-widget.js`) была собрана из
голых `.ui-card` со строками текста: статус «Подключено · id … · токен до …» отдельной карточкой,
статистика поста строкой «просмотры N · лайки N…», аналитика — SVG 132×64 без подписей дней.
Ник аккаунта сервер уже отдавал (`/api/threads/status` → `live.username`), но страница его не
показывала. Утверждён макет `threads-redesign` (лента в духе Threads, композер справа, 4 карточки).

## Решение

- Меняется только вид; API, данные, роуты, `web/threads.js` — без изменений.
- Шапка — родной `<header>` (ADR-147): `<h1>` + `.ph-s`, вкладки `#th-tabs` (`.ui-tabs`) и статус
  `#th-status` уезжают в `.ph-tools` — на ПК справа от заголовка, на телефоне под подзаголовком.
  Статус: «Подключено · @username · токен до ДД.ММ.ГГГГ» (ID аккаунта не показывается), карточки
  «Аккаунт» нет.
- «Мои посты»: ПК ≥1101 px — две колонки флексом (лента + липкий «Новый пост» 408 px), уже — одна
  колонка, композер сверху. Без своего `grid-template-columns` (ADR-341).
- Счётчики поста: значок + число + подпись со склонением (1 лайк / 2 лайка / 5 лайков); склонение —
  та же однострочная `plural(n, a, b, c)`, что в `analytics_app.js`/`seo-v2.js` (общего модуля нет).
- Аналитика: `.ui-auto` (`--min:460px` → 2×2 на ПК, столбиком на телефоне), плитка-значок, 7
  столбиков с подписями дней (день недели — `T00:00:00Z` + `getUTCDay`).
- Цвета — только токены `--ui-*` (в т.ч. `--ui-*-soft*`, `--ui-shadow-sm`); кнопки — роли `.btn`,
  `.tbtn`, `.btn-sm` без своих стилей; поля — `inpCss()` (свои фон/рамка у `#th-text` убраны);
  пустые состояния — общий `.ui-empty`; тосты — `pltToast` без изменений.
- Спрайт: добавлены `i-repeat-2`, `i-menu` (Lucide, lucide-static 0.460.0); `i-heart`, `i-calendar`,
  `i-clock`, `i-zap` уже были. `ICONS_V` 31 → 32, `habits-sw.js` SHELL `?v=32`, кэш `habits-v148`.
- Попутно: выбор вкладки по `#хэшу` — `Object.hasOwn(panels, name)` (раньше `#constructor` находил
  «панель» в прототипе и ронял `showTab`).

## Проверка

Локальный стенд (настоящие `ui.css` v105, `theme.css`, собранный кодом `themeVars/btnCss/inpCss`
из `server.js` с `THEME_DEFAULTS`, `page-header.js`, `toast.js`, `loc-time.js`; API — заглушки),
Chromium/Playwright, 1440×900 и 390×844, светлая и тёмная: 107 проверок OK, консоль без ошибок
(кроме ожидаемых 403 insights в сценарии «нет прав»). На сервере — ручная проверка по README.

## Последствия

- Плюс: страница на общих компонентах (`.ph-tools`, `.ui-tabs`, `.ui-empty`, `.ui-auto`), видно
  ник, счётчики читаются словами, аналитика с днями.
- Минус: отличия от макета там, где макет противоречит правилам платформы — кнопки не «пилюли»
  (роли из `/set`), нет хлебных крошек и капс-киккера «ИНТЕГРАЦИИ» (ADR-147), поле поиска без
  своей пилюли (`inpCss`), тост — платформенный `pltToast`.
- `server.js` меняется одной строкой (`ICONS_V`) → рестарт web-interface.
