## Риски

- `server.js` (1,2 МБ) снят `read_file` целиком, но патч проверен на этой копии; на сервере — только после dry-run.
- `ICONS_V` 32 меняет адрес спрайта на всех страницах: одна повторная загрузка `icons.svg` у всех (так и задумано).
- Стенд: `theme.css` — дефолты `THEME_DEFAULTS` без сохранённых в `/set` значений; без `sidebar.js`/`mhead.js`/
  `ui-forms.js` (на мобиле шапка статична, как у `mhead.js`). Реальные отступы/цвета `/set` могут чуть отличаться.
- `refreshStatus`/`loadPosts` по-прежнему зовут `r.json()` без `r.ok` (как было; логику не меняли) — при 401 будет
  прежнее «Не удалось проверить статус»/тост.
- Время поста «сегодня/вчера» считается в поясе устройства (как раньше `toLocaleString`).
- Липкий композер на ПК опирается на высоту `header.ph` (ResizeObserver → `--th-sticky`); если шапка не липкая — `top:12px`.
